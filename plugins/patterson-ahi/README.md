# patterson-ahi

The Animal Health International domain plugin: production animal distribution to cattle,
dairy, swine, poultry, and equine operations. Install as
`patterson-ahi@patterson-ahi-plugins`.

## What arrives by reference

Deep engineering, design, and writing capability is not duplicated here. This repository's
`.claude/settings.json` enables `patterson-engineering@patterson-corp` (CI/CD, Azure
environment/compute/storage, monitoring standards) and `patterson-brand@patterson-corp`
(palette, typography, voice) alongside this catalog.

## Provenance and licensing
