# Skills

Four skills ship with the plugin. Each carries `_SOURCES.md` (origin and confidence) and
`REFERENCES.md` (canonical locations) per the Patterson provenance convention.

## handle-product-recall

Use when a manufacturer issues a recall or withdrawal, when a product quality issue is
reported from the field, or when someone asks which customers received a specific lot.

The method separates notification from investigation: establish scope from the
manufacturer notice, freeze inventory before counting, trace every shipment by lot to the
delivery, notify veterinarians before operations, and close by reconciling shipped
against recovered.

## model-territory-economics

Use when evaluating whether to serve a new production animal territory, when a route is
losing money, or when assessing whether a regional acquisition will pay for itself.

A five-step model - demand, route, cost per stop, contribution per stop, break-even
density - tested against twelve-month switchable density and the seasonal trough, not
the average.

## lot-traceability-on-fabric

Use when designing or querying lot-level traceability data on Microsoft Fabric. See
[Lot traceability](/fabric/lot-traceability) for the full design.

## bootstrap-animal-health-intl

Use when onboarding the plugin for real use. Runs the structured interview that fills the
catalog's recorded `[TBD]` gaps - sources, brand, coding standards, team conventions,
roster, and skills - and lands the answers in the repository through a pull request.
